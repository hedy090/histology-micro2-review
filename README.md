# Histology + Micro II Quick Review

Offline study app: normal histology atlas and comparisons, Micro II pathology slides
(course 器官 / 診斷 / 描述 answers), 考古 past exams, and flashcards.

Open `index.html` in a browser, or publish with GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root).

Also included: `Micro II study guide.pdf`, `Micro II 考古 review.pdf`.
